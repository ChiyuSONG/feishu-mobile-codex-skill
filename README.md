# 飞书远程 Codex

[English](README_EN.md)

把飞书变成本地 Codex 的轻量手机入口。

你可以在手机上连续发送任务，不必等上一条完成；电脑离线时消息继续留在飞书，Codex 恢复后会按顺序处理。简单结果直接回复，复杂结果可以整理成私有飞书文档。

## 你可以用它做什么

- 在飞书群里直接给本地 Codex 发任务；
- 一个群稳定对应一个本地项目，修改群名不会影响连接；
- 连续发送多条消息，Codex 按顺序处理；
- 电脑离线时先把事情发到飞书，不必另外找地方记录；
- 短结果直接回复，长教程、表格和复杂结果使用私有飞书文档；
- 用自然语言调整自动巡检、查看 Codex 用量或设置提醒；
- 使用中文或 English 对话。

Codex 仍然负责理解需求、编辑项目、运行工具和完成任务；飞书只是一个流畅、可靠的移动入口。

## 安装

### 1. 安装 Skill

把本仓库地址发给 Codex，让它安装仓库中的 `skill/feishu-codex-remote`。

也可以手动将 [`skill/feishu-codex-remote`](skill/feishu-codex-remote) 复制到 Codex Skills 目录，然后重启或刷新 Codex。不要把整个仓库复制成一个 Skill。

### 2. 一句话开始配置

在 Codex 中打开准备连接的本地项目，然后发送：

> 使用 `$feishu-codex-remote`，把当前项目连接到我的飞书。尽可能自动完成，只在需要我扫码、登录或授权时提醒我。

Codex 会检查环境、创建独立的 Python 环境、协助配置飞书应用、建立群聊绑定、安装 Listener 和启动 Hook，并测试消息能否正常往返。

通常只需要你完成：

1. 扫码或登录飞书；
2. 选择正确的飞书账号或租户并同意授权；
3. 必要时将 App Secret 粘贴到安全输入位置；
4. 首次看到 Hook 安全提示时，审核并信任 `Starting Feishu Remote Listener`。

project key、chat ID、thread ID、Listener 路径等内部配置由 Codex 自动处理。

## 开始使用

连接成功后，直接在飞书群里说你想做什么：

- `检查项目里最近的改动并运行测试。`
- `我接下来会连续发三条要求，全部收到后按顺序处理。`
- `把完整结果整理成飞书文档。`
- `先记录这件事，等我补完信息再开始。`

电脑或 Codex 关闭时不会执行任务，但消息仍保留在飞书。下次打开或恢复 Codex 时，启动 Hook 会启动 Listener，并继续处理积压消息。

## 自动巡检

默认每小时运行一次。它会检查 Listener、补拉可能遗漏的飞书消息、推动积压任务继续处理，并报告 Codex 用量。

第一次巡检会完整说明用途。之后如果你没有修改，默认只发三句：

> 状态：Listener 正常，待处理 0，处理中 0，失败 0。
>
> Codex 用量：5 小时额度剩余……；7 天额度剩余……。
>
> 提示：可以用自然语言修改巡检、设置提醒或增加其他用法。

巡检会发起一次轻量 Codex 运行并消耗相应额度。你可以直接改变它：

- `只在发现待处理消息、失败或异常时通知我。`
- `不要报告 Codex 用量。`
- `把自动巡检改成每两小时一次。`
- `暂停自动巡检。`

## 把巡检当作备忘提醒

提醒功能适合记住一件未来还要跟进的事：Codex 会保存这项待办，并在自动巡检到达指定时间后提醒你。

例如，你要持续跟进一份材料，可以说：

> 从明天上午 10 点开始，每次巡检都提醒我提交材料，直到我说已经完成。

之后说：

> 材料已经提交，停止提醒。

如果只想收到一次提醒，可以说：

> 明天下午 3 点以后，下一次巡检时提醒我给朋友回电话，只提醒一次。

这不是独立的准点闹钟：提醒依赖电脑、Codex 和自动巡检。当指定时间电脑未运行时，它会在恢复后的下一次巡检提醒。需要严格准点的日程，请使用飞书日历或手机闹钟。

## 卸载

不需要运行命令，直接对 Codex 说：

> 卸载飞书远程 Codex。保留飞书对话和文档，先告诉我会移除什么，然后自动完成。

Codex 会先列出准备移除的内容，确认后再卸载本 Skill 添加的 Listener、启动 Hook、自动巡检和本地 Skill，不影响其他任务。

默认保留恢复备份，也不会删除飞书对话、群聊或已经生成的飞书文档。如果还要删除本地凭据、缓存和历史状态，请明确补充：`同时清除全部本地数据`。

## 支持环境

- Windows：已完成本地自动测试；
- macOS：已完成适配和模拟测试，在真实 Mac 验证完成前属于实验性支持；
- Python：需要 3.10 或更高版本。缺少环境时，Codex 会先说明需要安装什么。

## 隐私与安全

- 不需要公网回调或公开服务；
- App Secret 和 OAuth Token 保存在仓库外，Windows 使用 DPAPI，macOS 使用 Keychain；
- 生成的飞书文档会关闭公开链接分享并验证设置；
- 一个群只绑定明确指定的本地目录，不根据群名或消息内容猜测项目；
- 仓库不保存私人路径、飞书 ID、凭据、对话或运行状态。

更多说明请参阅 [SECURITY.md](SECURITY.md)。
